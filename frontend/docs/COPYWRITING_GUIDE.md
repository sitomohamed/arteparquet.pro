# Copywriting Guide

## Arteparquet Website Copy Standards

### Overview

Every word on the Arteparquet website must serve a purpose: to inspire, build trust, and convert visitors into clients. This guide ensures consistent, effective copy across all pages.

---

## Voice & Tone

### Brand Voice Attributes

| Attribute | Description | Example |
|-----------|-------------|---------|
| **Confident** | Assured expertise without arrogance | "Trasformiamo spazi" not "Cerchiamo di fare del nostro meglio" |
| **Warm** | Approachable and human | "Raccontaci il tuo progetto" not "Compila il modulo" |
| **Expert** | Knowledgeable but accessible | Technical accuracy without jargon overload |
| **Italian** | Authentic Italian expression | Natural language, not translated |
| **Aspirational** | Elevating but attainable | Paint a picture of transformation |

### Tone Variations by Context

| Context | Tone | Example |
|---------|------|---------|
| Headlines | Bold, poetic | "L'eccellenza scolpita nel legno" |
| Body copy | Warm, informative | "Ogni listello racconta una storia..." |
| Service descriptions | Expert, reassuring | "Utilizziamo tecniche di levigatura..." |
| CTAs | Direct, inviting | "Richiedi una consulenza" |
| Forms | Friendly, simple | "Come ti chiami?" |
| Error messages | Helpful, human | "Ops! Questo campo è obbligatorio" |

## Writing Principles

### 1. Benefits Over Features

```
❌ "Utilizziamo levigatrici professionali"
✅ "Il tuo pavimento tornerà come nuovo, senza polvere in casa"

❌ "Offriamo parquet prefinito"
✅ "Un pavimento pronto da vivere in pochi giorni"
```

### 2. "You" Focus

```
❌ "Siamo esperti in restauro parquet"
✅ "Il tuo parquet antico merita le mani giuste"

❌ "La nostra azienda opera dal 2004"
✅ "Da oltre 20 anni, realizziamo i sogni dei nostri clienti"
```

### 3. Active Voice

```
❌ "I lavori vengono eseguiti da professionisti"
✅ "Professionisti al lavoro sul tuo progetto"

❌ "Il preventivo sarà inviato entro 24 ore"
✅ "Riceverai il preventivo entro 24 ore"
```

### 4. Specificity

```
❌ "Abbiamo molta esperienza"
✅ "20+ anni di esperienza, incluso il Teatro alla Scala"

❌ "Operiamo in molte zone"
✅ "Operiamo in tutta Italia, dalla Lombardia alla Sicilia"
```

### 5. Sensory Language

```
❌ "Parquet di qualità"
✅ "Legno che profuma di natura, caldo sotto i piedi"

❌ "Finitura professionale"
✅ "Superfici lisce come seta, riflessi che danzano con la luce"
```

## CTAs (Calls-to-Action)

### Primary CTAs

| Location | Text |
|----------|------|
| Header | Preventivo Gratuito |
| Hero | Richiedi una Consulenza |
| Service page | Richiedi Preventivo per [Servizio] |
| Portfolio | Vuoi un risultato simile? |
| Contact | Invia Richiesta |

### Secondary CTAs

| Action | Text |
|--------|------|
| Learn more | Scopri di più |
| View portfolio | Vedi i nostri lavori |
| Call | Chiama Ora |
| WhatsApp | Scrivici su WhatsApp |
| Download | Scarica la Guida |

### CTA Writing Rules

1. Start with a verb
2. Be specific about the outcome
3. Keep it short (2-4 words ideal)
4. Create urgency when appropriate
5. Match the user's intent

```
Messaggio: Descrivi il tuo progetto, le dimensioni, i tuoi desideri...
```

```
Campo obbligatorio: "Per favore, compila questo campo"
Email non valida: "Inserisci un'email valida"
Phone non valido: "Inserisci un numero di telefono valido"
Success: "Perfetto! ✓"
```

```

Messaggio: "Più dettagli ci dai, meglio possiamo aiutarti"
Contatto: "Ti risponderemo entro 24 ore"
```

## SEO Copywriting

### Title Tag Formula

```
[Primary Keyword] | [Benefit/Differentiator] | Arteparquet

Examples:
Posa Parquet | Maestri Posatori dal 2004 | Arteparquet
Restauro Parquet | Ex Team Teatro alla Scala | Arteparquet
```

### Meta Description Formula

```
[Hook] + [Value Prop] + [Credential] + [CTA]. Max 160 chars.

Example:
Posa parquet professionale in tutta Italia. Ex team Teatro alla Scala. 
20+ anni di esperienza. Preventivo gratuito. ☎ 389 240 7827
```

### H1 Rules

- One H1 per page
- Include primary keyword naturally
- Make it compelling, not just descriptive

## Words to Use

| Instead of | Use |
|------------|-----|
| servizi | soluzioni, arte, esperienza |
| prodotti | materiali, essenze, legni |
| lavori | opere, realizzazioni, progetti |
| clienti | persone, famiglie, partner |
| azienda | atelier, studio |
| preventivo | consulenza, proposta |

## Words to Avoid

| Avoid | Why |
|-------|-----|
| Economico, cheap | Undermines premium positioning |
| Migliore, best | Generic, unbelievable |
| Qualità | Overused, meaningless |
| Professionale | Expected, not differentiating |
| Leader | Arrogant, cliché |

## Proofreading Checklist

- [ ] Spelling correct (Italian)
- [ ] Grammar correct
- [ ] Brand voice consistent
- [ ] Benefits over features
- [ ] Active voice used
- [ ] Specific not vague
- [ ] CTAs are clear
- [ ] No jargon unexplained
- [ ] Reads naturally aloud
- [ ] SEO keywords included naturally
